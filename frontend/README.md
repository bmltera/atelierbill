# Atelier Bill

A cinematic, staticly exported portfolio for Atelier Bill.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Development

```bash
npm install
npm run dev
```

## Production Build

This site is configured for static export.

```bash
npm run build
```

The output will be in the `out/` directory.

## Testing the Availability Engine

```bash
npm run test
```
